emergency_node_dispatch
/datum/emergency_node_dispatch

Tracks the round's node request from the player verb through admin review to the drop.

Vars

approval_timerTimer that approves the pending request.
request_idIncrements per request, so an old admin link cannot resolve a newer request.
requester_ckeyckey of whoever made the pending request, so they can be told the outcome.
requester_namekey_name of whoever made the pending request, for logs.
stateWhere the current request is in its lifecycle.

Procs

denyCancels the pending request and starts the denial cooldown.
get_drop_turfReturns the drop turf for the current map, or null if it is unset or unusable.
get_refusalReturns why this user cannot make a request right now, or null if they can.
launchSends the pod, or returns to idle if the drop site somehow stopped being usable during review. (This is what we call a bad day for engineering.)
notify_adminsSends admins the request with its approve and deny links.
notify_requesterMessages the requesting player if they are still connected and something bad has happened.
submit_requestHandles the player verb: confirms, then opens the admin review window.
